Explorador de tabelas

Esta página só funciona publicada num site — ela não abre corretamente se você apenas clicar duas vezes no arquivo no seu computador, porque carrega uma tabela de cada vez, sob demanda. Nenhuma tabela é combinada com outra aqui; a única forma de ir de uma tabela para outra é o link "ver perfil", que segue o nome do deputado até deputados-chave.csv.

Código-fonte e dados publicados: github.com/maximusminus/cldf-painel
