o painel

102 tabelas publicadas, 23 páginas de pergunta, 25 perfis de deputado(a). Todo número nesta pasta foi recalculado no momento da construção a partir das tabelas em data/derived/ — veja fontes e metodologia para a lista completa, com o que cada tabela é e de onde cada número veio.

O explorador abre qualquer uma das 102 tabelas, uma de cada vez, mas só funciona quando esta página está publicada num site — não abre corretamente se você apenas clicar duas vezes no arquivo no seu computador.
